# Test Task: GREEN-API Interface

A web interface built with pure JavaScript (Vanilla JS) to interact with GREEN-API methods.

## 🚀 Features
- **Get Settings** (`getSettings`): Retrieve current instance settings.
- **Get State Instance** (`getStateInstance`): Check the current status of the WhatsApp instance.
- **Send Message** (`sendMessage`): Send text messages to a specific phone number.
- **Send File by URL** (`sendFileByUrl`): Send documents or media files via a direct link.

## 📦 Getting Started
1. **Clone the repository** to your local machine.
2. **Open `index.html`** in any web browser (using VS Code Live Server is recommended).
3. **Enter your credentials:** Provide your `idInstance` and `apiTokenInstance` from your GREEN-API personal dashboard to start testing.
